## 📌 Project Overview

**NileFlow Pay Analytics** is my pre-final capstone project for the **Data Analysis Diploma at SIS Academy**. It simulates a real-world Egyptian FinTech company (*NileFlow Pay*) and delivers a complete analytics pipeline — from messy raw data to a polished, multi-page interactive Power BI dashboard.

The project demonstrates the full data analyst workflow:

- 🧹 **Data Cleaning & Preprocessing** with Python (Pandas & NumPy)
- 🗂️ **Data Modeling** with a structured relational schema in Power BI
- 📊 **Interactive Dashboard Design** across three business-focused pages
- 🎨 **Conceptual Branding** — an AI-assisted logo and brand identity built to give the project a realistic FinTech presentation

> **Note:** *NileFlow Pay* is a fictional brand created solely for educational and portfolio purposes. All data is simulated and does not represent a real company or real financial transactions.
